TartanMatch

Towards Universal Dense Matching Across Modalities

Hyeokjoon Kwon*, Jiting Cai*†, Ruogu Li*, Kritan Bhandari, Geethika Hemkumar, Parv Maheshwari, Yuheng Qiu, Yuchen Zhang, Sebastian Scherer, Wenshan Wang

Robotics Institute, Carnegie Mellon University

* Equal contribution † Corresponding author

Paper (PDF) BibTeX Interactive demos

Abstract

Robotic platforms combine complementary sensors to maintain perception across diverse operating conditions, but dense correspondence methods are typically designed for RGB or for a small set of modality pairs. Relying on pair-specific models scales poorly with the number of sensors and forgoes potential positive transfer across modality pairs. We introduce TartanMatch, a unified model for dense correspondence across all 25 ordered pairs among RGB, event, thermal, depth, and projected LiDAR. TartanMatch adapts an RGB-pretrained correspondence model to modality-specific representation and learns all sensor pairs within one shared network using a mixture of real and synthetic data. On zero-shot real-world benchmarks, TartanMatch reduces endpoint error over the strongest per-pair baseline by 61.9% (cross-modal) and 49.6% (same-modal). We further show that joint training improves average matching accuracy over pair-specific training, especially on challenging cross-modal pairs. These results demonstrate that broad multimodal coverage and strong matching performance can coexist in a single model.

Why match across sensors?

Robots carry several kinds of sensors because each one fails in different conditions. In the heavy snow below, the RGB camera is almost washed out, while the thermal camera still shows the car and LiDAR still measures the scene’s shape.

To use these sensors together, a robot has to know which pixel in one sensor’s image corresponds to which pixel in another’s. Existing matchers are mostly built for RGB, or for one specific pair such as RGB and thermal. With five sensor types there are 25 ordered pairs, and training a separate model for each does not scale.

What TartanMatch predicts

Given a source image and a target image from any two of the five sensors, TartanMatch predicts where every source pixel appears in the target, and whether that point is visible in both views. Moving the source pixels to their predicted locations should reproduce the target’s layout while keeping the source’s appearance.

Key results

  • One network with a single set of weights handles all 25 ordered pairs of RGB, event, thermal, depth, and projected LiDAR.
  • On real-sensor datasets never seen in training, its matches are off by 61.9% fewer pixels on cross-modal pairs and 49.6% fewer on same-modal pairs than the best competing method for each pair (average endpoint error).
  • Training all pairs together is more accurate than training one model per pair, and the gain is largest on the hardest cross-modal pairs.
  • It runs in 27.8 ms per image pair on an H100 GPU, 7.4 times faster than MatchAnything (RoMa).

How it works

TartanMatch starts from UFM, a dense matcher pretrained on RGB images. It keeps one shared matching network and adds only a small input layer so that each sensor’s data can be fed in without discarding what makes it different.

Sensor inputs
RGB goes in unchanged, and thermal intensity is copied into three channels. Events are stacked into 15 time bins. Depth and projected LiDAR become log-depth plus a validity mask, so missing measurements are marked rather than filled in. A learned 1 × 1 projection maps events and depth-like inputs to three channels. These projections are the only new parameters.
Shared matcher
Every pair uses the same network: a DINOv2 encoder, a transformer that exchanges information between the two images, and DPT heads that output a flow vector and a covisibility score for each pixel.
Two-stage training
For the first 10 epochs the encoder is frozen while the input projections and matcher adapt. For the next 35 epochs the whole network is fine-tuned.

Training data

No single dataset covers every sensor pair, so training mixes 16 real and synthetic sources across indoor, outdoor, aerial, and driving scenes, about 650,000 pairs per epoch. Ground-truth matches come from native optical flow labels or from known geometry, and some thermal images are synthesized. Evaluation uses five real-world benchmarks held out from training.
